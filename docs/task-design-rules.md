# What makes a task usable

正常的 prompt，然后生成了 ai slop。而不是在 task prompt 里面就包含 slop 或者说到 slop。那是 hint。

## 2026-09-20

五个 task 里有四个犯了这条，删掉了：

- `devlog-plain-language`：prompt 里写了「遇到绕不开的专业词就在原地用大白话解释一句」，直接教了写法。
- `ci-rule-announcement`：要宣布一条禁止 slop 句式的检查规则，prompt 只能把那些句式列出来。
- `translation-fix-note`：讲的就是把别扭的翻译腔改顺。
- `media-caption-cut`：讲的就是删掉一句没用的话，prompt 还给了删的理由。

留下 `essay-correction-note`。它是一篇长文修订后要写的说明，讲的是引用、物理和结论，跟文风无关。

同一天另外删掉了三个更早写的题：`library-evening-return`、`repair-diary`、`waitlist-cancellation`。它们的 prompt 本身没有 hint，但都是凭假设出题，没有真实出处，也没有模型跑过。

说清读者是谁没问题，教怎么写就不行。

## 三种泄题方式

题面不能做这三件事，做了就不是诱发题：

1. **列出禁用词**。「不使用「好的」「当然」」「不得写「由于」「因为」」。模型照着躲就行，不必自己判断。
2. **给一份带套话的草稿让模型改**。改写不是生成，模型没有机会自己决定要不要写套话。
3. **把套话本身印在题面上**。哪怕只是当材料、当要逐字保留的原话、当反面例子，模型都已经在上下文里拿到了那个句式。

第三条最容易漏。`protected-quote` 的题面写着「（一）这不是延期，而是取消。」，要求逐字保留。看起来是在考保护引文，实际上模型读完题，这个句式已经在手边了，后面那段正文用不用它，已经不是自发的选择。

## tasks/ 里的十道旧题

同样的毛病：题面直接给出要避开的写法。有的列出禁用词（「好的」「当然」「尽快」「由于」），有的给一份带套话的草稿让模型改，有的干脆把「不是……而是……」印在题面上要求照写。模型不必自己判断，照着删或照着抄就行。

改法是把这些限制从题面移进检查器。检查器该查的照查，模型不再被告知。八道题按这个改了，`scripts/selfcheck.py` 的 183 个样例仍然全过，说明检查器本来就不读题面，之前那些话只是在泄题。

三道没改，`task.toml` 里都写明了不是套话诱发题：

- `contrast-correction`、`status-update-multi-step` 第三轮：要求必须写出「不是……而是……」。那是有意的指令遵循检验，看模型会不会反射式回避而不读题。
- `protected-quote`：题面把这个句式作为要逐字保留的原话给出来。整道题的机制就建立在给出句式上，去掉它题就不成立了。

## 记一次改坏的

第一轮改完，我说 `protected-quote` 因为这次编辑「变好了」，理由是模型要自己分辨哪句该照抄、哪句该改写。这个判断是错的：句式已经在题面上，分辨得再准也不改变模型拿到了它这个事实。

第二轮想补救，把题面改成不含那句原话。结果更糟：检查器和参照答案仍然要求逐字保留「这不是延期，而是取消」，而新题面根本没提这句话，任何照着题面写的回答都不可能通过。`selfcheck.py` 照样全过，因为它拿检查器对样例，不拿检查器对题面。这类不一致它查不出来。

已回滚到一致的状态。教训有两条：题面和检查器要一起改，别指望 selfcheck 发现题面问题；以及有些题的机制就依赖泄题，这种题改不动，只能如实标成别的类型。
